# Handoff — deep-large-memory v2.0.0 simplification + logging

## Summary

Complete refactor of `@sistema54/deep-large-memory` opencode plugin from 3 files (~490 lines) to single file (~500 lines with logs). All tests pass (23/23).

## Changes

### Architecture
- Merged `src/db.ts` + `src/memory.ts` + `src/index.ts` → `src/deep-large-memory.ts` (single file)
- Removed `sessions` table entirely (was write-only metadata, never queried)
- Removed `ensureSession()` function
- Removed FK constraint from turns (no sessions table)
- Merged `storeTurn()` + `storeConversationTurns()` → single `storeTurns()`
- Exported functions: `sessionHash`, `sanitizeFtsQuery`, `contentOverlap`, `compressMemories`, `MemoryHit`, `TurnRow`

### DB
- Same path: `~/.config/opencode/storage/deep-memory.db`
- Fresh start — old DB was deleted manually during migration
- Only `turns` + `turns_fts` (FTS5) + triggers. No `sessions`.
- All 23 performance PRAGMAs preserved

### Logging (new feature)
- `log_level` option: `"silent" | "info" (default) | "debug"`
- Info: `Stored: N turns`, `Recall: N memories (X chars)`
- Debug: skip reasons, FTS details, overlap exclusions
- Module-level `_logLevel` variable + `log()` helper function

### Preserved
- FTS5 + BM25 search
- Dedup by content_hash + unique index
- FIFO pruning (keep limit)
- Age filter (max_age_days)
- isRealUserMessage heuristic
- 40% overlap filter (avoids injecting recent context)
- Sentence-boundary truncation in compressMemories
- Token budget (length/4 estimation)

### Deploy
- Plugin deployed to `~/.config/opencode/plugins/deep-large-memory.ts`
- `opencode.jsonc` configured with local path + `log_level: "debug"`
