# Handoff — 2026-07-01 (sesión actual)

## Estado

Investigando por qué el plugin deep-memory v2.1.0 no carga en opencode.
Diagnóstico: probablemente `bun:sqlite` no disponible en runtime de plugins,
o auto-loading de `plugins/` no funciona para `.ts`.

## Último paso

Se creó `src/sqlite-test.ts` — plugin minimalista para probar si `bun:sqlite`
funciona en el runtime de opencode:

1. Crea DB en `~/.config/opencode/storage/hello.db`
2. Crea tabla, inserta "ok", lee, escribe resultado en `sqlite-test.log`
3. Si funciona → el problema es otro
4. Si falla → `bun:sqlite` no está disponible
